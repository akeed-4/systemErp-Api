# تعليمات العمل على الخادم

قبل أي تطوير في هذا المستودع، اقرأ `BACKEND_PROJECT_GUIDE.md` أولاً. استخدمه خريطةً مختصرة، ثم اقرأ أجزاء المعمارية ذات الصلة فقط؛ لا تبدأ بقراءة المشروع كله.

## طريقة العمل

- حافظ على اتجاه الاعتماد: `ERP.Api → ERP.Service → ERP.Core`.
- قواعد العمل والتحقق المالي تكون في الخدمات، لا في Controllers ولا في الواجهة.
- عند تغيير عقد endpoint، راجع DTO والعقد والخدمة والواجهة المستهلكة له.
- تغييرات الكيانات تتطلب فحص إعدادات EF Core والهجرات الموجودة.
- احمِ عمليات الدفاتر والمخزون والعزل بين المنشآت والصلاحيات من أي تجاوز.
- لا تشغّل اختبارات أو أوامر تحقق إلا إذا طلب المستخدم ذلك.
- حدّث الدليل عند تغير بنية عامة أو قرار معماري، لا لكل تغيير صغير.
