# دليل جداول قاعدة البيانات

هذا الدليل يشرح جداول مخطط EF Core الحالي، مجمعة حسب نطاق الكيان. مصدر العدد هو `ERP.Service/Data/Migrations/ErpDbContextModelSnapshot.cs`؛ لذلك لا تُحسب الكيانات المضمنة أو جداول الترحيلات القديمة. العدد الحالي **153 جدولاً**. أسماء الجداول مكتوبة كما تظهر في SQL Server.

|---|---:|
| المحاسبة والمبيعات والمشتريات والموارد البشرية | 64 |

| نقاط البيع | 16 |
| البيانات والخدمات المشتركة | 47 |
| **الإجمالي** | **153** |

## ملاحظات

- الأعداد أعلاه تخص جداول مخطط قاعدة بيانات ERP الخاص بالمنشأة كما يظهر في لقطة EF Core، ولا تشمل جداول ASP.NET Identity أو جداول إدارة المنصة التي قد تكون في قاعدة بيانات مستقلة.
- المجموعات تصف نطاق الكيانات وليس حدوداً صارمة للاستخدام؛ فمثلاً `Customer` و`Product` و`Warehouse` جداول مشتركة تستخدمها المبيعات والمشتريات والمخزون ونقطة البيع.
- قد تتغير الأعداد عند إضافة أو حذف كيانات. حدّث هذا الدليل بعد تحديث لقطة النموذج في migration جديدة.
